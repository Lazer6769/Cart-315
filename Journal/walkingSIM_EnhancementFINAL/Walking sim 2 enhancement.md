
# the backrooms enhanced 

for my enhancement I want to add more rooms to my game, 
why? so the player has more space to cover and so the player isn't just walking around in the same room 

## | Rooms |
I do want the rooms to be unique even if it is the simplest idea that I have

### | MainRoom 1 OG | 

Room 1 is the base room that was originated from the first version of the walking sim it was supposed to be a generic backrooms/liminal space inspiration which involved the following 

- backrooms like aesthetic by making the room yellow 
- environmental sounds 
- player sounds (jumping, walking, landing, sprinting)
- mechanic being sprinting so the player isn't walking the entire time 
- random sounds playing at 30 second intervals to make the player anxious as if to question if they're alone or not 
- and a fall off sound to add slight comedy to the horrific atmosphere 

All of these made a decent walking sim while also adding some inspiration from something That I found would be perfect for a walking sim 

Why backrooms/liminal spaces. Because I found that there can be endless possibilities to where the player can end up, there can be literally anything in the backrooms/liminal spaces which I found to be interesting since I can make any room That I desire but for time and simplicity just some basic rooms and ideas for what those rooms should be 

### | Room 2 Stairs | 

Room 2 is a generic stair room originally with the pillars I wanted them to have stairs as well but unfortunately it would've been too many stairs for the game to handle so I only made the stairs run along the wall, now the reason as too why I would even put stairs and pillars in such a huge room, because I wanted the room to be ominous which is why I also added a sound that reverberates across the room which adds more suspense to this room in particular, also I wanted to make the room as dark as possible only having the stairs emit light which tells the player that they must follow the yellow bricked stairs.
